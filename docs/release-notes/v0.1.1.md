**OpenYog** is a free, open-source desktop client for MySQL, MariaDB,
PostgreSQL, SQLite and MongoDB, on Linux and Windows, with the layout and
shortcuts SQLyog users already know.

**New in 0.1.1:** ready-to-run packages for every Linux distribution. The
AppImage and the portable archive start on any of them without installing
anything, and there are native packages for Ubuntu/Debian, Fedora/openSUSE
and Arch.

## Downloads

**Windows 10/11 (64-bit)**

- `openyog-0.1.1-windows-x64-setup.exe`: the installer
- `openyog-0.1.1-windows-x64.zip`: portable, unpack and run

**Linux (x86_64)**

- `openyog-0.1.1-x86_64.AppImage`: any distribution, make it executable and run
- `openyog-0.1.1-linux-x86_64.tar.gz`: any distribution, unpack and run `./openyog`
- `openyog_0.1.1-1_amd64.deb`: Ubuntu, Debian, Mint
- `openyog-0.1.1-1.x86_64.rpm`: Fedora, openSUSE
- `openyog-0.1.1-1-x86_64.pkg.tar`: Arch Linux, Manjaro

The AppImage, .tar.gz, .deb and .rpm come with their own Qt and libraries.
All they need is glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 and
later).
