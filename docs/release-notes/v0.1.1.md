OpenYog 0.1.1 brings packages for every Linux distribution.

## Downloads

| Platform | File |
|---|---|
| Windows 10/11 (64-bit), installer | `openyog-0.1.1-windows-x64-setup.exe` |
| Windows, portable | `openyog-0.1.1-windows-x64.zip` |
| Any Linux (x86_64) | `openyog-0.1.1-x86_64.AppImage` |
| Any Linux, portable | `openyog-0.1.1-linux-x86_64.tar.gz`: unpack, run `./openyog` |
| Ubuntu / Debian / Mint | `openyog_0.1.1-1_amd64.deb` |
| Fedora / openSUSE | `openyog-0.1.1-1.x86_64.rpm` |
| Arch Linux / Manjaro | `openyog-0.1.1-1-x86_64.pkg.tar` |

The AppImage, .tar.gz, .deb and .rpm include their own Qt and libraries and
need glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 and later).

## Changes since 0.1.0

- New packages: AppImage, portable .tar.gz, .deb and .rpm, tested on
  Debian 12, Ubuntu 24.04, Fedora, openSUSE Tumbleweed and Arch Linux.
- The Arch package now has a standard name: `openyog-<version>-1-x86_64.pkg.tar`.
- MongoDB: the document grid sizes its columns to their contents.
- Building from source works on Debian and Ubuntu (the libpq headers are found
  under `/usr/include/postgresql`).

## Known limitations

- The Windows build has been tested under wine, not yet on real Windows machines.
- No HTTP tunnel, scheduled backups or scheduled jobs yet.
