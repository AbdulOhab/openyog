The first release of OpenYog: a desktop database client for **MySQL,
MariaDB, PostgreSQL, SQLite and MongoDB**, on Linux and Windows. It is an
independent GPL fork of the SQLyog Community Edition source with a Qt 6
interface, not affiliated with Webyog or Idera.

## Download

- **Windows (64-bit)**: `openyog-0.1.0-windows-x64-setup.exe` installs
  OpenYog with a Start menu entry (and a desktop icon if you want one);
  uninstall it from *Apps & features*. Or take
  `openyog-0.1.0-windows-x64.zip`, unpack it anywhere and run
  `openyog.exe` from that folder.
- **Arch Linux / Manjaro**: `openyog-git-0.1.0.*-x86_64.pkg.tar.zst`,
  installed with `sudo pacman -U openyog-git-*.pkg.tar.zst` (it pulls in
  Qt 6 and the database client libraries it needs).
- Other Linux distributions: build from source, as the README describes.

## What's in it

- **Connections** to MySQL/MariaDB, PostgreSQL, SQLite and MongoDB, with
  SSL/TLS and SSH tunnels (on Windows too). Saved passwords go to the
  system keychain; the open connections and query tabs come back on the
  next start.
- **Query editor**: syntax highlighting, autocomplete that knows your
  tables, columns and foreign keys, several result grids at once, query
  history; a result keeps its first 10,000 rows and counts the rest.
- **Table data**: edit, add and delete rows in the grid, applied together
  in one transaction.
- **Schema**: create and alter tables, indexes, foreign keys, views,
  procedures, functions, triggers and events; SQL dumps and database copy.
- **Schema Designer**: a database as a diagram you arrange (it remembers
  where you put things); drag a column onto another table's to add a
  foreign key.
- **Query Builder**: build a SELECT by pointing; AND and OR conditions;
  save and open what you built.
- **Schema Sync** and **Data Sync**: compare two databases (tables,
  columns, keys, foreign keys, views, routines and triggers, or the rows)
  and get the script that makes one match the other.
- **Import External Data**: rows from a CSV file, an Excel workbook (.xlsx)
  or another connection into a new or existing table, with column types
  guessed from the data.
- **MongoDB**: browse databases and collections, find with filter, sort and
  projection, run aggregation pipelines and commands, and edit, insert and
  delete documents as text that keeps every value's type; indexes,
  import and export.

## Good to know

- The Windows version has been tested under wine, not yet on real Windows
  machines. Problems there are especially welcome as
  [issues](https://github.com/AbdulOhab/openyog/issues).
- Not there yet: the HTTP tunnel and the Advanced connection settings,
  scheduled backups and jobs.
