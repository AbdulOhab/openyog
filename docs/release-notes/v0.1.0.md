The first release of **OpenYog**, a free, open-source desktop client for
MySQL, MariaDB, PostgreSQL, SQLite and MongoDB on Linux and Windows.

![OpenYog](https://raw.githubusercontent.com/AbdulOhab/openyog/main/docs/screenshots/query-editor.png)

## Downloads

| Platform | File |
|---|---|
| Windows 10/11 (64-bit), installer | `openyog-0.1.0-windows-x64-setup.exe` |
| Windows, portable | `openyog-0.1.0-windows-x64.zip` (unzip and run `openyog.exe`) |
| Arch Linux / Manjaro | `openyog-git-0.1.0.*-x86_64.pkg.tar.zst` (`sudo pacman -U openyog-git-*.pkg.tar.zst`) |

## Highlights

- Connections to five databases, with SSL/TLS and SSH tunnels
- Query editor with schema-aware autocomplete and several result grids
- Schema Designer, Query Builder, Schema Sync and Data Sync
- Import from CSV, Excel and other connections
- MongoDB: browse, query, aggregate and edit documents

## Known limitations

- The Windows build has been tested under wine, not yet on real Windows machines.
- No HTTP tunnel, scheduled backups or scheduled jobs yet.
